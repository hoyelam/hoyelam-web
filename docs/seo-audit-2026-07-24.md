# SEO Audit — 2026-07-24

## Executive summary

Overall technical SEO health is good after remediation. The production build contains 338 indexable HTML pages and now passes the repository audit with zero errors and zero warnings.

The review covered crawlability, sitemap membership, canonical URLs, title tags, meta descriptions, headings, internal links, local images, rendered JSON-LD, and content inventory. Rendered markup was also spot-checked on the live homepage, an article, and the 404 route.

## Resolved technical findings

### Legacy meta descriptions

- **Impact:** High
- **Evidence:** Many imported descriptions were shorter than 70 characters; 13 exceeded 160 characters.
- **Fix:** Short descriptions now combine with the article excerpt. Long descriptions are capped at 160 characters.
- **Status:** Resolved across all rendered pages.

### Long title tags

- **Impact:** Medium
- **Evidence:** 15 title tags exceeded 60 characters.
- **Fix:** Search titles are now capped at 60 characters without changing the visible H1.
- **Status:** Resolved across all rendered pages.

### Article image layout stability

- **Impact:** Medium
- **Evidence:** Local article images lacked intrinsic width and height attributes.
- **Fix:** The Markdown image pipeline now reads local image metadata and emits width and height.
- **Status:** Resolved for local article images.

### Imported image alt text

- **Impact:** Medium
- **Evidence:** 124 rendered images had empty alt text.
- **Fix:** When an imported image has an adjacent italic caption, the caption is now used as alt text.
- **Status:** Improved from 124 to 41 empty alt attributes. The remaining empty values are valid for decorative images but should be reviewed manually if they convey information.

### Regression coverage

- **Impact:** High
- **Evidence:** The previous audit only inventoried frontmatter, remote covers, and thin posts.
- **Fix:** `npm run seo:audit` now builds the site and checks rendered pages, canonicals, sitemap membership, metadata, H1s, JSON-LD, internal links, image paths, alt attributes, and image dimensions.
- **Status:** Resolved. The command exits non-zero for technical SEO regressions.

## Verified healthy signals

1. `robots.txt` allows crawling and references the sitemap index.
2. Every indexable page has a unique self-referencing HTTPS canonical.
3. The sitemap contains exactly the rendered indexable canonical URLs.
4. No broken internal links or local image paths were found.
5. Every indexable page has exactly one H1, and every post has valid `BlogPosting` JSON-LD.

## Content opportunities

### Thin legacy posts

- **Impact:** Medium
- **Evidence:** 149 posts contain fewer than 250 words.
- **Recommendation:** Use Search Console impressions and positions to prioritize posts worth expanding or consolidating. Do not noindex solely by word count.

### Remote social images

- **Impact:** Low
- **Evidence:** 207 posts use Unsplash URLs for social previews.
- **Recommendation:** Migrate the most-visited posts to local 1200×630 images first to reduce third-party dependency.

### Generic social image fallback

- **Impact:** Low
- **Evidence:** Six posts use the site-wide social image.
- **Recommendation:** Create page-specific social images when those posts show meaningful impressions or sharing activity.
